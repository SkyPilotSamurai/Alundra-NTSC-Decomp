# Alundra Rando Tracker
----------------------------------------------------------------------------------------------------
Open Alundra_Rando_Tracker.exe and use Import JSON File from the menu, locate the Alundra 
rando json file that you want to track

Open Bizhawk, go to Tools/Lua console, and from that menu open Alundra_Rando_Tracker_Bizhawk
and tracking will begin

You can change which checks you want to track, before loading a file with the checks menu,
current location tracking is on by default, you can turn on/off in the display menu

Note: Current location "Overworld" tracks both indoor and outdoor areas, but shops are not included

Display menu options and what they do:
Show Crests and Fire Wand = Pink/Purple (If an location has a Crest or Fire Wand)

Show Location Colors = Colored will be colored based on how many checks are left
Grey: None, White: 1, Green: 2, Blue 3+

Show Armor Locations = Orange (If an location has Armor, useful for newer runners)
